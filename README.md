# QTRA

Code release in preparation for **Question-Conditioned Temporal Change Encoding
for Change Detection Question Answering and Grounding in Remote Sensing**.

QTRA denotes the Question-Conditioned Temporal Residual Adapter.

## Status

This is a private release-preparation repository. The runnable implementation,
installation instructions, training and evaluation commands, and checkpoint
download instructions are being checked before publication. They are not yet
available in this repository.

Datasets and pretrained third-party weights will not be redistributed here.
Dataset acquisition instructions and third-party attribution will accompany
the implementation. License information is being checked before source code
is added; no blanket license is assigned by this placeholder.
